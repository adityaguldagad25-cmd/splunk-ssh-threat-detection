# Splunk SSH Threat Detection

## Project Overview
This project analyzes SSH authentication logs using Splunk Enterprise.

## Objectives
- Identify failed login attempts.
- Find successful logins.
- Analyze suspicious source IP addresses.
- Detect usernames targeted by repeated login attempts.

## Tools Used
- Splunk Enterprise
- SPL (Search Processing Language)
- SSH Authentication Logs

## Sample Findings
- Failed login attempts: 4
- Source IP: 192.0.2.15
- Successful login username: aditya

## Dashboard
The dashboard displays failed login attempts by IP and login activity by username.
